# Modules and Limitations

- **Diagnostics:** Reports Python/system details, writable data paths, and external-tool detection/version-probe results. Finding an executable on `PATH` does not verify authenticity, version compatibility, or an end-to-end integration.
- **DNS OSINT:** Queries A, AAAA, MX, NS, TXT, and CNAME through `dnspython` and the configured resolver. Each record type reports `SUCCESS`, `NO_ANSWER`, `NXDOMAIN`, `TIMEOUT`, or `DNS_ERROR`. A DNS query discloses the domain to the resolver.
- **RDAP:** Sends an HTTPS request to the public RDAP service, with a timeout and a 512 KiB response limit. Internet access and service limits apply.
- **Sherlock:** Uses an external executable, validates the username, invokes it without a shell, applies a timeout/output limit, and reports URLs present in its output. It does not verify identity. The adapter was tested with mocks only; no real binary was tested.
- **Network:** DNS resolution and a single-port TCP connectivity check. TCP is not a port scan and does not determine vulnerability. TCP requires explicit authorization and enforces configured `allowed_targets` when the list is non-empty.
- **Web:** Sends a limited GET request and revalidates redirects. It blocks loopback, private, link-local, reserved, and other non-public destinations. Python's default HTTPS client validates TLS, but LupoHack does not perform detailed certificate-chain/date analysis. This is not a ZAP scan.
- **Files:** Computes streaming hashes and basic metadata. It does not follow symlinks, modify files, or execute content.
- **OWASP ZAP:** Detects a local executable, attempts version reporting for supported launchers, and can launch the local GUI after exact confirmation. It has no ZAP API, target, spider, or scan integration; real-binary behavior is unverified.
- **Metasploit Framework:** Detects `msfconsole`, attempts a version check, and can launch its local interactive console after exact confirmation. It supplies no target, module, exploit, payload, or command. Real-binary behavior is unverified.
- **Tool Manager:** Provides `check`, `show`, individual installation plans, supported confirmation-gated installers, and post-install version rechecks. `AVAILABLE` means only that an executable was found. `version_check_status` reports whether its fixed version command succeeded.
- **Configuration:** Stores validated JSON locally. `allowed_targets` applies to TCP. V1 always requires explicit authorization for TCP/web, regardless of the `require_scope_confirmation` field. The `require_scope_confirmation` and `allow_external_targets` keys are currently accepted but not read by runtime policy; do not rely on them to grant or remove access.
- **Reports:** Provides JSON/CSV/TXT exports and local history. Nothing is sent automatically; explicit OSINT/web queries do contact their corresponding external services.
