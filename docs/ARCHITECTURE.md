# Architecture

LupoHack is a layered local Python application. `cli.py` provides direct command parsing, scope checks, and dispatch. `menu.py` provides the categorized interactive navigation over the same services, while `console.py` contains dependency-free ASCII branding. `modules/` contains DNS/RDAP, network/TLS, web, and file services. `integrations/` contains the bounded external-process runner, external-tool adapters, and presence-only tool inventory. `core/` contains validation, result models, exports, and local history. `config.py` manages validated local JSON configuration. No source files were relocated in this update because the existing package separation already matches those responsibilities.

The process runner invokes fixed argument arrays with `shell=False`, a timeout, and an output limit. The Tool Manager uses a fixed executable catalog; free-form user input is not converted into shell commands. Sherlock has a dedicated adapter. ZAP and Metasploit are limited to local executable detection/version checks and confirmation-gated launches.

Storage is local. LupoHack has no server or telemetry. The only additional Python runtime dependency is `dnspython`; system applications are not included in Python requirements. The Core setup does not install external tools. HTTP inspection validates public destinations and revalidates redirect destinations. It does not pin DNS resolutions, so this is not a guarantee against every DNS-rebinding topology. TLS inspection uses the standard trust store and hostname verification for one explicitly authorized endpoint, without scanning other ports. The quick tool inventory checks names on `PATH` only and does not launch them.
