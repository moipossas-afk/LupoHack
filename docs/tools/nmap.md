# Nmap integration — retired

This page is retained only as a historical link target for earlier LupoHack documentation. The Nmap integration was removed from the LupoHack V1.0.0 preparation branch because its licensing implications were not resolved for distribution under the project's MIT License.

The current LupoHack release does not provide Nmap commands, detect or install Nmap, invoke it, or parse its output. This page is not an installation or usage guide. The removal does not alter the Git history of the earlier integration.
