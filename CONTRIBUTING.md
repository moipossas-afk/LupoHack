# Contributing

The canonical public source repository is [moipossas-afk/LupoHack](https://github.com/moipossas-afk/LupoHack). Clone it with `git clone https://github.com/moipossas-afk/LupoHack.git`. See the [README](README.md#repository) and [installation guide](docs/INSTALLATION.md) for setup instructions.

Use Python 3.11+, create a virtual environment, install `python -m pip install -e ".[dev]"`, run `pytest` and `ruff check .`. Add tests that do not depend on the Internet. Describe security changes, limitations, and the tested platform. Do not submit secrets, histories, personal artifacts, or target results.
